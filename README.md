# HelpDesk

직원이 문의를 티켓으로 등록하고 상태를 관리하는 사내 헬프데스크 웹 서비스

## 기술 스택
- Spring Boot 2.7.3
- Thymeleaf
- MyBatis
- MySQL
- Spring Security (세션 기반 Form Login)

- [x] 문의 목록 조회 (페이징 · 상태 필터)
